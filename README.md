# Занятие «Работа с БД // ДЗ»

## Установка

```bash
pip install -r requirements.txt
```

## Запуск простых примеров без ORM

```bash
python examples/00_init_db.py
python examples/01_create.py
python examples/02_read.py
python examples/03_update.py
python examples/04_delete.py
python examples/05_select_examples.py
python examples/07_cursor_values.py
python examples/08_select_keywords.py
```

## Запуск ORM-примера

```bash
python examples/06_orm_example.py
```

## Запуск тестов

```bash
pytest
```
